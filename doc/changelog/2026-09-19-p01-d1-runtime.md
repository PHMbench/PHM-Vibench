# P01 D1 source execution and frozen evaluation

The P01 physical-group data access, source trainer, preflight, and adoption
implementation now live in `experiments/p01/`. Paper-repository entry points
delegate to this implementation instead of owning another trainer.

`TSPNFusionLoss` retains its previous positional arguments and default numerical
behavior. Keyword-only `risk_reference` and `consistency_target` implement the
declared O/UO/RO/RC comparisons. Training records actual sample/pair schedules,
domain risks/weights, candidate state, stable window log probabilities, and costs.

The PU binding uses existing metadata/H5 and global physical-bearing partitions;
it does not read held-out waveforms or fabricate reference history. A source-only
original TSPN trainer and the existing ResNet1D comparator share the data/evaluator.

Frozen export separates source selection, assessment, fresh-process source
restoration, and permanent-test release. Offline analysis consumes only prediction
artifacts; latency measurement consumes only source-validation input on GPU0.
Focused software tests do not constitute completed industrial experiments.

Source-artifact analysis accepts the completed source-only prediction paths,
while diagnostic plotting reads saved analysis tables without loading waveforms,
checkpoints, or recomputing estimates. Cost summaries read explicit run artifacts,
retain missing and failed slots, and count shared label pools once across reused
predictors and seeds. These software paths and the recorded PU configurations do
not assert that the real D1 experiment or its held-out evaluation is complete.
