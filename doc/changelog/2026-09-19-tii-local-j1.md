# Matched TII tokenizers and the local J1 boundary

M_01_ISFM now provides matched support/ordinary two-branch tokenizers and a pure
encoder interface. A registered DG.tii_joint Task and native H5 Data Factory path
apply physical projection, source-only balanced RMS, fixed group/window sampling,
equal-source CE and source-validation checkpoint selection. The existing AdamW,
Trainer and public CLI remain the runtime. Target readout and offline query
validation live in Task Components; invalid identities and query contamination
fail before grouping or NLL. Fractional labels/channels are rejected without
truncation. Float64 validation preserves the fixed 1e-8 checkpoint tie rule.

The bounded CPU fixture config is configs/experiments/tii/m0_tensor_fixture.yaml.
Actual commands, checkpoints, source-validation predictions and test limitations
are retained under reports/tii_local_j1. These establish software behavior only.
Read-only qualification inspected 18 local industrial H5 files, 19 dataset IDs
and 49,855 original-record metadata rows. Zero corpora and zero held-out folds
satisfied the frozen qualification requirements: J1 is NO-GO, and real micro-run
and downstream comparisons were not run. No raw industrial signals are committed.

Local focused tests pass. The one complete pytest attempt stopped during
collection because the selected LQ_signal environment lacks streamlit; it is not
a full-suite pass. No scientific performance or baseline-valid claim is made.
