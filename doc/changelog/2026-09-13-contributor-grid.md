# Static contributor grid

The README contributor wall no longer depends on the third-party `contrib.rocks` image service.
Both English and Chinese homepages now render the current GitHub contributor list as a static HTML grid using GitHub-hosted user avatars.

The core-team section, full GitHub contribution-history link, Slack, Feishu, Issues, Discussions and Star History links are unchanged.
The grid is intentionally updated manually when needed; no permanent contributor bot or README-rewrite workflow was added.
