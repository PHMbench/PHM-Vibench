# Installed scientific operators

The public `phmfactory research <phase> --config <yaml>` command executes the
configured Task Factory scientific operator through the existing configuration
resolver. It does not add an algorithm registry or parallel paper frameworks.
Ordinary Pipeline invocation rejects research configurations and scientific
execute modules. Non-gradient tasks describe their actual data/model objects.

`research preflight` resolves configuration and the task module without fitting,
data qualification or result creation. Input archives, checkpoints, selection
artifacts and new output destinations are explicit phase inputs. Incompatible
inputs fail before execution.

The command reports the observed installed distribution version and RECORD
identity without invoking Git. Source imports cannot borrow another installed
distribution's identity. A declared source revision is separate from that
observation and never establishes a clean working tree. A software fixture
result establishes neither scientific novelty nor empirical PHM benefit.

| `DG.expert_intervention` | `configs/experiments/p04/expert_intervention.yaml` | Role assignment and frozen-gate intervention contrasts |

Source training/search accepts only train/val packs; independent matching/test packs use explicit checkpoints, saved normalization and source identities. Historical G050 is not re-executed or relabelled.
