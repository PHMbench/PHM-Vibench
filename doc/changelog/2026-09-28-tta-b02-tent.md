# B02: one-step Tent on an ordered target stream

The bounded Python path now composes strict source loading, the B01 target-loader
contract, x-only prediction, evaluator-only labels and one BN-affine entropy/Adam update.
The task component owns its optimizer; no new Trainer, Task registry, CLI, data adapter,
source-data access or result format is introduced. Existing B00/B01 behavior is unchanged.

The official MIT source is DequanWang/tent at
`e9e926a668d85244c66a6d5c006efbd2b82e83e8`. The original one-step pre-update-logit behavior
and train-mode BN/dropout are retained; BatchNorm1d is an explicitly tested extension of
the original BatchNorm2d operator. BN-free/unsupported models fail without replacement.
Only checkpoint-only persistent online/continual, closed-set, predict-then-update batches
are executable. Learning rate is explicit; target-label tuning is not provided.

Local Python 3.13.5 / torch 2.10.0+cpu: the initial integrated suite passed 238 tests,
including 71 B02 cases. A subsequent malformed-checkpoint counterexample showed that
Adam accepts absent moments and starts a new trajectory. The bounded fix now requires
complete first/second moments, matching shapes and optimizer steps for all adapted
parameters. The final regression passed 242 tests, including 75 B02 cases; totals overlap.
A new-process algorithm-state restore matches the next prediction, model/Adam state and
RNG. It is not a stream-cursor/evaluator/whole-experiment resume.
The first wheel, built with the available pip/setuptools backend, passed its 71 B02
tests outside the checkout in the existing dependency environment. This is not clean
full-dependency installation evidence; the isolated environment lacked Torch/pytest.
An actual ResNet1D and native target loader use bundled Dummy and a synthetic source
checkpoint; no industrial data or trained industrial source is accessed.

The initial oracle attempt failed two BN1d/BN2d dropout comparisons. A second attempt
failed four affine-gradient comparisons. A direct BN-gradient diagnostic located the
non-contiguous channels-last 2d fixture path; both oracle fixtures now use the same
contiguous layout before normalization/dropout. The upstream source, production model
inputs and declared tolerances were not changed to mask these failures.

Existing public-package CI gains the installed-wheel B02 tests outside the checkout,
including a real subprocess restore. Exact-head Actions and independent review remain
merge gates; local success does not claim those gates or E3/benchmark-ready status.
No SAR/CoTTA/EATA, EMA, replay, reset, SFDA, target HPO or GPU result is included.
Rollback is a normal revert of this bounded change.
