# 四分类变工况轴承仿真：显式 bearing4 profile

## 范围和依赖

作者指定PHMFactory论文W09/T22及后续数值验证共用一套四分类轴承变工况仿真。本变更在PR #327的 `6e1b5337076ef92deae87f816b7d0682235ad2ef` 上扩展已有 `scripts/prepare_simulated_phm.py`，不复制第二生成器、loader或trainer。旧legacy三类模式保留；`--profile bearing4` 是新研究显式入口。

科学协议维护在论文仓 `paper/core/simulation_experiments.md`，本文件仅记录实现与验证。其他项目的实测数据要求和历史结果不被这个profile改变；不得将旧三类结果改名为四类结果。本分支不合并PR #327/#328/#329或其他PR，不更新dev/main或注册表成熟度。

## 实现假设

健康、内圈、外圈、滚动体四类。理想纯滚动、外圈固定、9个滚动体、直径比0.2、零接触角；故障阶次为BPFI 5.4、BPFO 3.6、BSF 2.4、FTF 0.4。滚动体事件采用2×BSF的理想双接触近似。相位由瞬时转速积分；冲击经过按模拟实例固定的衰减共振响应，附加轴同步背景与类无关噪声，不添加标签编码直流偏置。

这些是未标定的信号模型假设，不是完整动力学模型或原论文复现。依据：[McFadden & Smith 1984](https://doi.org/10.1016/0022-460X(84)90595-9)、[Randall & Antoni 2011](https://doi.org/10.1016/j.ymssp.2010.07.017)。具体转速、随机参数和样本量是项目选择，不由这些文献直接规定。

固定12800Hz、16384点、两种成对观测视图；幅值任意单位。12个模拟实例×6工况×4类构成288记录设计。工况含900/1200/1500/1800 rpm恒速和900↔1800 rpm线性升/降速。实例0–5训练、6–7验证、8–9适应、10–11评价；每个实例含所有工况和类别。配置仍须按源工况0–2、目标3–5和主Partition显式过滤，不能读取全表就声称DG。

现有 `CSV_Signal` reader只读取配置的 `sensor_a` 或声明的其他通道。真实类别、可推断类别的记录ID/文件名、故障阶次、脉冲数、生成种子与共振参数不得进入无标签模型输入。

## 已执行命令和结果

```bash
python scripts/prepare_simulated_phm.py --profile bearing4 --pilot --seed 2026 --output <new-data-root>
```

`--pilot` 是完整设计的固定子集：实例0/6/8/10，工况0/3/4，四类；同种子同公式。2026-11-04在本地CPU实际生成48条，每类12条，每条16384×2；全部有限，四个Partition的模拟实例无重叠。已有输出目录被拒绝，不覆盖历史数据。

|---|---|---|
| CSV与重新生成数组 | 最大绝对误差7.450580596923828e-09；同种子数组完全一致 | 有限pilot，不是完整数据集运行 |
| 原生CSV_Signal单通道读取 | 全部48条与独立NumPy float32读取精确一致 | 原reader源自dev@fae561da；未执行全DataFactory |
