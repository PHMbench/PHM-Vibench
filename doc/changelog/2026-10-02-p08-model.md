# P08 explicit shared-head conditioning model

Adds `ISFM/M_P08_PhysicalConditioning.Model(args_model, metadata)` using the maintained E_01_HSE without copying its implementation. Coordinates are `physical` or `index`; fusion is `none`, `film`, `token_concat`, or `late_concat`. Forward accepts measured `fs` and the Data Factory's source-encoded `condition`. File and domain IDs never enter prediction. Exposes stored and active parameter counts separately; inactive parameters are not capacity matching.

Focused tests cover real HSE coordinates, shared initialization, gradients, detached conditioning, explicit patch indices and checkpoint restoration. This addition alone does not qualify source splits, record-level metrics, baseline tuning or a full P08 experiment. No main/release promotion or empirical result.
