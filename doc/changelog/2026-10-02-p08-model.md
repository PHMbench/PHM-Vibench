# P08 explicit shared-head conditioning model

Adds `ISFM/M_P08_PhysicalConditioning.Model(args_model, metadata)` using the maintained E_01_HSE without copying its implementation. Coordinates are `physical` or `index`; fusion is `none`, `film`, `token_concat`, or `late_concat`. Forward accepts measured `fs` and the Data Factory's source-encoded `condition`. File and domain IDs never enter prediction. Stored and active parameter counts are separate; inactive parameters are not capacity matching.

The concurrent native prototype at `838ad940` is retained as a merge parent. Its explicit component-name guards, fixed-patch positive overfit test, and shared-reader dtype support are retained in the active tree. Its alternate data/task/config protocol is archived in Git history because it is not equivalent to the frozen factorial and model-selection protocol. See `docs/P08_EXPERIMENT_A.md` for the single active entrypoint and exact target-access boundary.

Focused tests exercise actual HSE coordinates, shared initialization, gradients, detached conditioning, explicit patch indices, checkpoint restoration, and small-batch learning. They do not establish industrial baseline qualification or empirical superiority.
