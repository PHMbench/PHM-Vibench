\begin{abstract}
This entrypoint records the current submission-readiness state for the
Fuzzy-XFD paper targeting IEEE Transactions on Fuzzy Systems. The only accepted
claims at this stage are the presence of fuzzy rule-level implementation assets,
the availability of rule/membership visual artifacts, and the declared
PHM-Vibench minimal reproduction contract. Multi-seed CWRU/XJTU metrics,
six-baseline comparisons, ablations, TOP recent-work representative runs, and
SOTA wording remain blocked until same-protocol artifacts are generated under
the local two-RTX-4090 compute constraint.
\end{abstract}

\noindent\textbf{Keywords:} fault diagnosis, fuzzy rules, explainable AI,
rule-level evidence, submission readiness.

\section{Scope}

This file replaces the previous template manuscript entrypoint with a
compilable evidence snapshot. It is not a final submission manuscript. Numerical
performance, safety, and SOTA claims are intentionally withheld unless they map
to accepted local artifacts.

\section{Compute Constraint}

Accepted experiment commands must bind the local devices explicitly, for
example:

\begin{verbatim}
CUDA_VISIBLE_DEVICES=0 python main.py \
  --config paper/UXFD_paper/Paper_fuzzy_XFD/configs/vibench/min.yaml \
  --override trainer.num_epochs=1
\end{verbatim}

Runs may use only GPU 0, GPU 1, or both local RTX 4090 GPUs. Any external TOP
method that cannot fit this budget must remain literature-only or
resource-blocked and cannot support SOTA performance claims.
