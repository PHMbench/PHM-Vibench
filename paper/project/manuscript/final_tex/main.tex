\begin{abstract}
This checkpoint manuscript specifies a neural-symbolic evidence contract for
explainable fault diagnosis within the UXFD paper family. The current repository
state exposes a constrained NSN/TSPN\_UXFD configuration, six command-bound
baseline entries, seven ablation entries, proposition validation hooks, a
scripted cross-method mapping report, and a source-backed sibling-submodule
mapping report. These artifacts are sufficient to remove the previous
placeholder manuscript and missing-figure blocker, but they are not sufficient
for IEEE Transactions submission readiness. Accepted CWRU/XJTU multi-seed
experiments, local RTX 4090 GPU metadata, TOP representative artifacts, explicit
negative mappings, and SOTA evidence remain blocked.
\end{abstract}

\begin{IEEEkeywords}
Explainable fault diagnosis, neural-symbolic learning, evidence contract,

\end{IEEEkeywords}

\section{Introduction}

Fault-diagnosis papers that combine neural models with symbolic or physical
constraints are vulnerable to overclaiming when equations, figures, and result
tables are not tied to runnable artifacts. Paper 06 therefore treats the
neural-symbolic contribution as an evidence contract before treating it as a
performance claim. The contract requires that every proposition, mapping, and
comparison row name its command, artifact path, acceptance status, and remaining
blocker.

The current contribution is limited and explicit. The repository now contains a
configuration-level neural-symbolic path, a baseline and ablation matrix, and a
source-backed mapping report over the sibling UXFD papers. It does not yet
contain accepted same-protocol performance evidence or a SOTA claim.

\section{Blocked Claims}

The current manuscript must not claim SOTA, final proposition support, exact TOP
method reproduction, GPU feasibility, or same-protocol superiority. The strict
blockers are:
\begin{itemize}
  \item no accepted CWRU/XJTU multi-seed baseline table;
  \item no accepted GPU model/runtime metadata from local GPUs 0 and 1;
  \item P2 has only scope-limited synthetic hooks and no accepted real-data
  robustness protocol;
  \item no accepted TOP representative command/log/artifact mapping;
  \item no accepted mapping-impact artifacts;
  \item no SOTA claim is allowed from the current matrix.
\end{itemize}

\section{Conclusion}

This checkpoint removes the placeholder manuscript and missing example-figure
reference by binding Paper 06 to current repository artifacts. It narrows the
remaining work to accepted real-data experiments, GPU metadata, TOP
representative artifacts, explicit negative mappings, proposition cleanup, and
SOTA gating. Until those artifacts exist, the paper remains non-submission-ready.
