\begin{abstract}
This checkpoint records the current submission-readiness state of the
Explainable Fault Diagnosis Toolkit paper. The repository exposes a
PHM-Vibench minimal reproduction config, six command-bound diagnostic baseline
smokes, schema-valid historical Toolkit artifacts, and non-accepted smoke
artifacts for schema, metric-family, manifest, snapshot, and post-hoc-only
ablation surfaces. These artifacts remove the previous generic manuscript
placeholder, but they do not support IEEE Transactions submission readiness.
Accepted CWRU/XJTU or industrial multi-seed results, same-protocol Toolkit
ablations, TOP representative artifacts, complete local RTX 4090 metadata, and
SOTA infrastructure claims remain blocked.
\end{abstract}

\begin{IEEEkeywords}
Explainable fault diagnosis, benchmark toolkit, evidence contract,

\section{Scope}

This manuscript entrypoint is an evidence checkpoint. It replaces the previous
generic title, abstract, method, discussion, and conclusion placeholders with
the exact claims currently allowed by the repository. It intentionally avoids
claiming accepted performance, accepted TOP-method reproduction, GPU
feasibility, or SOTA.

\section{Ablation Checkpoint}

The Toolkit ablation smoke runner binds the reviewer-facing ablation surfaces to
concrete commands:
\begin{itemize}
  \item schema validation disabled;
  \item faithfulness/stability metric-family subset disabled;
  \item standardized manifest disabled;
  \item fixed seed and config snapshot disabled;
  \item post-hoc-only comparator mode.
\end{itemize}

The runner writes smoke-level \texttt{run\_meta.yaml} and \texttt{metrics.json}
artifacts with \texttt{accepted\_evidence=false}. These outputs prove artifact
shape and command binding only. They do not replace same-protocol accepted
ablation artifacts.

\section{Blocked Claims}

The paper remains non-submission-ready. The current blockers are:
\begin{itemize}
  \item no accepted CWRU/XJTU or industrial multi-seed six-baseline table;
  \item no accepted same-protocol Toolkit ablation table;
  \item no accepted TOP representative command, log, and artifact mapping;
  \item incomplete local RTX 4090 metadata in existing schema-valid packs;
  \item no accepted SOTA or submission-ready infrastructure claim.
\end{itemize}

\section{Conclusion}

This checkpoint makes the canonical Toolkit TeX entrypoint concrete and
traceable. The next accepted-evidence milestone is still experimental rather
than editorial: run the six-baseline and Toolkit-ablation matrices under the
same dataset split, seed protocol, preprocessing, metrics, TOP representative
policy, and local GPU metadata contract.
