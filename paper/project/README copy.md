# 研究计划书：NNSPN-MoE —— 基于物理机理约束的内在可解释故障诊断模型

## 1. 研究目标 (Research Objectives)

本研究旨在构建一个**物理同构（Physics-Isomorphic）**的深度学习模型。不仅要求模型“算得对”，更要求模型的**内部模块分工**与**信号处理的物理流程**一一对应。

具体目标如下：
1.  **专家模块物理化**：将黑盒的神经网络层替换为**“神经信号算子”**，每个算子被强制约束为只能处理特定的频段或特征（如低频、共振带、包络）。
2.  **路由决策显性化**：建立从**统计特征（如峭度）**到**算子选择**的透明映射规则，模拟人类专家的诊断思维（“因为峭度大，所以用包络解调”）。
3.  **可解释性量化验证**：不仅评估准确率，还要评估**“物理一致性得分”**，即模型选择的处理路径是否符合故障机理。

---

## 2. 核心科学问题与机理映射 (Key Scientific Questions & Mapping)

这是本研究最核心的部分。为了实现“精确的故障特征提取”，我们需要将**故障机理**清洗为具体的**专家设计约束**。

### 问题一：如何构建“术业有专攻”的物理专家？
我们将故障信号分解为不同的物理成分，并设计对应的专家模块。

| 目标故障类型 | 物理机理 (Expert Knowledge) | 信号特征表现 | **设计的专家模块 (Expert Design)** | **约束/实现方式** |
| :--- | :--- | :--- | :--- | :--- |
| **A. 转子不平衡 / 不对中** | 旋转频率及其倍频振动 | 能量集中在**低频段** (1X, 2X, 3X转频) | **低频通带专家** (Low-Freq Expert) | **低通滤波器算子**：强制截止频率 < 500Hz (可学习)，后续接简单的时域统计层。 |
| **B. 滚动轴承故障 (外/内圈)** | 缺陷引发的高频冲击共振 | 宽带冲击、**高频共振带**中的调制信号 | **高频包络专家** (Envelope Expert) | **带通滤波器 + 希尔伯特变换**：强制滤波器关注高频共振区 (2k-5kHz)，提取包络谱。 |
| **C. 齿轮磨损 / 断齿** | 啮合频率及其边带 | **中频段**的复杂调制、边带能量 | **边带分析专家** (Sideband Expert) | **倒频谱 / 梳状滤波器**：关注特定的啮合频率及其谐波间隔。 |
| **D. 随机噪声 / 干扰** | 环境白噪声 | 全频段均匀分布，无明显周期性 | **去噪专家** (Denoising Expert) | **小波阈值 / 软阈值算子**：仅保留大幅值系数，抑制背景噪声。 |
| **E. 复合故障** | 多种机制叠加 | 复杂的时频分布 | **残差专家** (Residual Expert) | **标准 MLP**：作为“全科医生”，处理上述物理算子无法完全覆盖的非线性残差。 |

### 问题二：如何让 Router 像人类专家一样思考？
Router 的输入不应是原始数据，而是**高级统计指标**。

* **人类逻辑**：观察到信号有很多尖峰（峭度大） -> 判断有冲击 -> 选择包络分析。
* **Router 设计**：
    * **输入**：[RMS (能量), Kurtosis (冲击性), Shape Factor (波形), Spectral Centroid (频率重心)]。
    * **决策逻辑**：
        * 若 `Spectral Centroid` 低且 `RMS` 高 $\rightarrow$ 激活 **低频通带专家**。
        * 若 `Kurtosis` 极高 $\rightarrow$ 激活 **高频包络专家**。

## 3. 渐进式实验安排 (Progressive Experimental Plan)

实验设计遵循 **Control Variable (控制变量)** 原则，逐步引入物理约束。

### 阶段一：基线与黑盒 MoE (Baseline Establishment)
* **目的**：确立性能下限，验证 MoE 架构本身（参数量增加）带来的增益。
* **设置**：
    * Baseline: 原始 NNSPN。
    * Blackbox MoE: Router 使用隐层特征，Expert 使用标准 MLP。
* **预期**：Blackbox MoE 准确率略高于 Baseline，但专家激活混乱（例如，处理不平衡故障时，所有专家都激活，无分工）。

### 阶段二：物理专家的“强制分工”验证 (Physical Experts Verification)
* **目的**：验证设计的“物理专家”是否真的能提取到对应的故障特征。
* **设置**：
    * **手动指定路由 (Hard-coded Routing)**：不训练 Router。
    * 强制将“不平衡故障”数据输入“低频专家”，将“轴承故障”数据输入“包络专家”。
* **预期**：
    * 在手动路由下，模型应能达到极高的准确率。
    * **反证实验**：如果将“不平衡数据”强制输入“包络专家”，准确率应显著下降。这将证明专家的**特异性**。

### 阶段三：可解释路由的学习与稀疏化 (Interpretable Routing)
* **目的**：让模型自动学会物理规则。
* **设置**：
    * 引入**物理特征 Router** (输入为统计量)。
    * 加入 **稀疏正则 (Sparsity Loss)**：限制每个样本 Top-1 激活。
    * 加入 **正交正则 (Orthogonality Loss)**：鼓励不同专家的输出特征互不相关。
* **预期**：模型在无人工干预下，针对轴承故障自动高概率激活“包络专家”。

### 阶段四：极限场景下的鲁棒性 (Robustness & Generalization)
* **目的**：物理模型的优势在于泛化和抗噪。
* **设置**：
    * **强噪声测试** (SNR = -6dB)：测试物理算子（如带通滤波）是否比纯 MLP 更抗噪。
    * **跨工况/跨设备**：在 CWRU 上训练，直接在 XJTU 上测试（Zero-shot 或 Few-shot）。
* **预期**：NNSPN-MoE 的性能衰减显著小于纯深度学习模型，因为物理规律（如共振解调原理）在不同设备间是通用的。

## 4. 预期结果与可视化 (Expected Outcomes)

### 1. 路径签名矩阵 (Path Signature Matrix) —— 核心证据
这将是一张热力图，横轴为故障类型，纵轴为专家 ID。
* **理想结果**：呈现清晰的**对角线或稀疏块状结构**。
    * 例如：[轴承内圈, 轴承外圈] 列对应 [包络专家] 行高亮；[转子不平衡] 列对应 [低频专家] 行高亮。
* **失败结果**：全图均匀分布（说明专家同质化，无物理分工）。

### 2. 路由决策边界图 (Routing Decision Boundary)
* 绘制 Router 输入特征（如 x轴=峭度，y轴=频谱重心）的二维散点图，颜色代表激活的专家。
* **预期**：看到清晰的决策边界。例如，高峭度区域主要被“包络专家”占据。

### 3. 单样本物理归因报告
针对一个具体的测试样本，生成自动化报告：

> * **Final Prediction**: Outer Race Fault.

## 5. 论文创新点 (Contributions)

1.  **提出了“物理同构”的 MoE 架构设计方法**：
    * 打破了传统 MoE 仅作为模型扩容手段的惯例，首次将**信号处理算子库**实例化为 MoE 的专家层，解决了深度学习模型结构与物理机理脱节的问题。

2.  **构建了基于统计特征的显式路由机制**：
    * 提出了一种**“统计量驱动”**的门控网络，替代了传统的“数据驱动”门控。这不仅降低了 Router 的拟合难度，更使得路由过程具有了直接的物理语义解释（模拟专家诊断流程）。

3.  **建立了故障诊断模型的内在可解释性验证范式**：
    * 不同于现有的类激活映射（CAM）等事后解释方法，本研究通过**专家特异性验证**、**路由一致性分析**和**跨域物理鲁棒性**，提供了一套验证模型是否真正“理解”物理机理的完整标准。

---

**总结**：
这个研究计划的核心在于**“去黑盒化”**。我们不是让网络自己去学所有的特征，而是利用领域知识（低频、包络、边带）预设好特定的“工具箱”（专家），然后训练一个聪明的“工头”（Router）根据信号的宏观特征（统计量）去调用正确的工具。这正是工业界最渴望的**可信 AI**。
