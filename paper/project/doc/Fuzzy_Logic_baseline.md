## 实验设计建议

### 核心对比维度

1. **模糊 vs 神经**: 模糊逻辑系统与传统神经网络对比
2. **规则可解释性**: 模糊规则的提取和解释
3. **不确定性处理**: 对噪声和模糊输入的处理能力
4. **计算效率**: 推理速度和资源消耗

### 模糊规则设计

#### 隶属函数优化
```python
# 示例：故障严重程度的隶属函数
severity = {
    'normal':      trimf(x, [0, 0, 0.2]),
    'light':       trimf(x, [0.1, 0.3, 0.5]),
    'moderate':    trimf(x, [0.3, 0.5, 0.7]),
    'severe':      trimf(x, [0.5, 0.8, 1.0])
}
```

#### 模糊规则提取
```python
# 规则示例
rules = [
    "IF 频率 IS high AND 振幅 IS high THEN 故障 IS severe",
    "IF 频率 IS medium AND 温度 IS normal THEN 故障 IS moderate",
    # ... 更多规则
]
```

### 评估指标

1. **性能指标**
   - 分类准确率、精确率、召回率
   - F1分数、AUC

2. **模糊特定指标**
   - 规则覆盖率 (Rule Coverage)
   - 模糊熵 (Fuzzy Entropy)
   - 隶属度拟合度

3. **可解释性指标**
   - 规则可理解性评分
   - 推理路径复杂度
   - 专家一致性验证
