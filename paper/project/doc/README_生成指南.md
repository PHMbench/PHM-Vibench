# README生成指南

## 📚 文档说明

本目录包含了为论文项目生成专业README文档的所有资源和模板：

- **README_Template_Outline.md** - 详细的模板大纲说明
- **README_Generation_Prompt_CN.md** - 中文Prompt生成模板
- **README_Generation_Prompt_EN.md** - 英文Prompt生成模板
- **README_Template_Example.md** - 完整的示例README

## 🚀 快速使用

### 1. 选择合适的Prompt版本

根据项目复杂度选择：

- **完整版**：复杂的、多实验的论文项目
- **简化版**：中等规模的项目
- **极简版**：快速原型或小型项目

### 2. 填写项目信息

在Prompt中填写以下信息：
```
- 论文标题：[您的论文完整标题]
- 项目名称：[GitHub仓库名]
- 研究领域：[如：故障诊断、机器学习等]
- 研究目标：[1-2句话描述]
- 主要贡献：[2-3个创新点]
```

### 3. 生成README

将填写好的Prompt输入到LLM（如GPT-4、Claude等）生成README。

### 4. 后期调整

- 根据项目特点调整内容
- 添加项目特定的配置和命令
- 更新链接和联系方式

## 💡 使用建议

### 最佳实践

1. **保持真实性**：确保所有命令和配置都经过验证
2. **定期更新**：及时更新项目状态和结果
3. **添加示例**：提供实际可运行的代码示例
4. **文档完整**：链接到详细文档和教程

### 常见错误避免

- ❌ 使用虚假的链接或路径
- ❌ 复制粘贴不相关的代码
- ❌ 忽略环境依赖说明
- ❌ 缺少故障排除部分

## 📋 检查清单

生成README后，请检查：

- [ ] 所有链接有效

- [ ] 配置文件路径正确
