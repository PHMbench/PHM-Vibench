## 📊 参数量详细计算

### 1. 信号处理器 (Conv1d)
```python
# Conv1d参数计算
in_channels = 2
out_channels = 3
kernel_size = 7
bias = True  # 默认包含bias
```

- **权重**: `in_channels × out_channels × kernel_size` = 2 × 3 × 7 = 42
- **偏置**: `out_channels` = 3
- **批归化**: `out_channels × 2` = 3 × 2 = 6 (mean + variance)
- **总计**: 42 + 3 + 6 = **51参数**

### 2. 专家网络 (3个专家)
每个专家的参数计算：
```python
# 专家1: Linear(256→128)
W1: 256 × 128 = 32,768
b1: 128

# 专家2: Linear(128→64)
W2: 128 × 64 = 8,192
b2: 64

# 专家3: Linear(64→10)
W3: 64 × 10 = 640
b3: 10
```

- **单专家总计**: 32,768 + 128 + 8,192 + 64 + 640 + 10 = **41,802参数**
- **3个专家总计**: 41,802 × 3 = **125,406参数**

### 3. 门控网络
```python
# Linear(256→64)
W_gate: 256 × 64 = 16,384
b_gate: 64

# Linear(64→3)
W_out: 64 × 3 = 192
b_out: 3
```

- **门控总计**: 16,384 + 64 + 192 + 3 = **16,643参数**

### 4. 分类器
```python
# Linear(10→64)
W1: 10 × 64 = 640
b1: 64

# Linear(64→5)
W2: 64 × 5 = 320
b2: 5
```

- **分类器总计**: 640 + 64 + 320 + 5 = **1,029参数**
