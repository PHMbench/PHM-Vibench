### 2. 物理专家模块实现

#### 🎯 低通专家 (LowPassExpert)
- **物理机理**: 低频段能量集中，通过低通滤波器突出低频特征
- **目标故障**: 转子不平衡、基础振动、低频机械松动
- **核心算子**:
  - 巴特沃斯低通滤波器 (500Hz截止)
  - 统计特征提取网络
  - 低频频谱分析
- **置信度计算**: 基于低频能量占比和特征激活强度

#### 🎯 谐波专家 (HarmonicExpert)
- **物理机理**: 转频谐波振动，基频与倍频并存
- **目标故障**: 转子不对中、齿轮故障、偏心故障
- **核心算子**:
  - 谐波分量提取 (基频及其倍频)
  - 谐波相位分析
  - 梳状滤波特征
- **置信度计算**: 基于谐波规律性和幅值衰减模式

#### 🎯 包络专家 (EnvelopeExpert)
- **物理机理**: 高频冲击共振，通过带通滤波+包络解调
- **目标故障**: 轴承外圈/内圈故障、滚动体故障
- **核心算子**:
  - 带通滤波器 (2000-5000Hz)
  - 希尔伯特变换包络提取
  - 包络谱分析
- **置信度计算**: 基于冲击特征和谱峰值

### 3. 统计路由器实现

#### 🚦 StatisticalRouter
- **输入特征**: 15种可解释统计特征
  - 时域特征：均值、标准差、方差、熵、峭度等
  - 频域特征：频谱均值、频谱重心
- **路由策略**:
  - 神经网络路由决策
  - 基于规则的调整 (物理约束)
  - 温度缩放和softmax
- **正则化**:
  - 稀疏性损失 (L1正则)
  - 负载均衡损失
- **可解释性**: 路由决策解释、专家权重分析

### 4. 完整MoE模型

#### 🤖 NNSPNMoE
- **专家数量**: 3个物理专家
- **特征维度**: 64维
- **分类器**: 3层MLP (128->64->类别数)
- **正则化**: 专家正交性、专家多样性、路由约束
- **模式切换**: 物理同构模式 ↔ 黑盒模式
- **解释功能**: 路径签名、专家激活分析、样本解释
