## 2. 覆盖不是模型计数

对 S1/S2 的每项必要角色，用一条实际采用记录连接：

```text
科学角色 → exact task/config → 当前实现 → E0/E1/E2 → 对应 E3/资源记录
```

一个模型可以覆盖多个角色，但同一 backbone 的别名或仅换宽度不能伪造独立证据。旧模型也可以满足角色，不要求必须新接入。弱于简单基线的合法负结果保留；“有用”不等于必须胜出。

只有所有适用的必要角色有实际证据，才声明科学覆盖完成。现在只冻结矩阵，未声明 S1/S2 已全部覆盖。

## 4. 两个首要 Task 合同——只冻结范围，不写实现

### S1：固定窗口监督分类

输入：按既有 Dataset 明确提供的信号、标签及 file/domain identity；布局从实际 model/config 取得，不要求重写所有旧模型为 BLC。新原生 BLC adapter 必须明确转置处。

禁止：标签作为模型的非协议输入；target-domain/test 数据用于 scaler/HPO/模型选择；隐式改类别集合、域或通道。

输出：对应标签集合的 logits，或明确声明的 features；Task 负责 loss、metric、optimizer；Trainer 负责设备和 selected checkpoint。

随机性/保存：训练随机策略显式；eval 是否确定按原算法；严格恢复当前承诺的完整状态。跨 seed 统计只能汇总同一个 estimator。

### S2：历史前缀到固定未来后缀的确定性点预测

输入：history [B,L,C]；目标由 Task 在模型外构建 [B,H,C]。首批无未来协变量、无不规则采样、无预测分布声明；不以 dummy zeros 冒充模型要求的额外输入。

禁止：目标后缀参与模型输入归一化、频率选择或 context embedding；测试集不得用于 early stopping、阈值/HPO 或选择模型。验证集仅按冻结的选择规则使用。

输出和 loss：一个 [B,H,C] 点预测；原始单位、归一化单位分别说明；Task 在冻结的 horizon/channel 支持上计算 MSE/MAE，不能先逐 batch 求平均再错误加权。

校准：本合同无阈值或概率校准。不支持的模型进入 Task 缺口，不删去其核心输入。

来源实现如训练全长重建而移植仅优化后缀，属于训练目标偏离；必须单独标变体，不能仅凭前向相同声称完整 E2。
