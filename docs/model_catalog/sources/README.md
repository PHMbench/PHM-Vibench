# Original catalogue source material

This directory stores repository-visible source exports from the original model/task
workbook used to seed the 187-row candidate study. They are historical input material,
not current support or E0 verification.

- [WORKBOOK_SOURCE_EXPORT.md](WORKBOOK_SOURCE_EXPORT.md) contains the parsed cell values
  from all six tabs of the exact saved workbook snapshot, including fields omitted from
  the compact working catalogue.
- [Task_Modules.csv](Task_Modules.csv) preserves the original 18-row Task planning sheet.

The working [MODEL_CATALOGUE.csv](../MODEL_CATALOGUE.csv) preserves the 187-row denominator
and current research disposition fields. It does not overwrite the source export.

Original scores, tiers, recommended waves, suggested paths and 'Existing' annotations are
historical planning inputs. They do not become VERIFIED, E0, E1, E2 or E3 evidence merely
because they appear in the source workbook.

The binary XLSX and conversation prompt package remain in the maintainer's delivery
archive; future repository audits do not require those out-of-band files because the
workbook cell values needed for candidate/source review are committed here.
